# 模型价格计算器

单文件网页版计算器：按 Token 单价、输入输出比例、缓存命中率估算调用成本（元）。

## 使用

直接双击打开 `index.html` 即可，无需安装、无需联网（无任何外部依赖）。

## 参数

| 参数 | 说明 | 默认值 |
|---|---|---|
| 输入价格 | 未命中缓存的输入单价，元 / 百万 tokens | 0 |
| 输出价格 | 输出单价，元 / 百万 tokens | 0 |
| 缓存价格 | 输入缓存命中部分的单价，元 / 百万 tokens | 0 |
| Token 总量 | 本次计算的 token 总数 | 1,000,000 |
| 输入 : 输出比例 | 输入与输出 token 数之比 | 0 : 0 |
| 缓存命中率 | 输入 tokens 中命中缓存的比例 | 0% |

默认除 Token 总量外全部置 0，需按目标模型的实际单价与用量填写。输入 : 输出比例为 0 : 0 时视为无效比例，按 1 : 1 计算（避免除零）。

## 计算公式

```
输入 tokens = 总量 × 输入占比 ；输出 tokens = 总量 × 输出占比
缓存命中 tokens = 输入 tokens × 命中率（按缓存价格计费），其余输入按输入价格计费
总价格 = 输入(未命中)×输入价 + 输入(命中)×缓存价 + 输出×输出价
实际单价 = 总价格 ÷ 总量（折算为元 / 百万 tokens）
```

结果区同时给出费用明细与费用占比。
